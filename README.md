# 🛍️ AuraStore - Modern E-Commerce Shopping Website

A modern, fast, and responsive e-commerce web application built with vanilla **HTML5**, **CSS3**, and **Modern JavaScript (ES6+)**. No build tools, zero dependencies, runs directly in any browser and can be hosted for free on **GitHub Pages** with one click.

---

## ✨ Features

- 📱 **Fully Responsive Design**: Pixel-perfect layout optimized for desktop, tablets, and smartphones.
- 🔍 **Real-time Live Search**: Instant filtering across product names, categories, and descriptions.
- 🏷️ **Dynamic Category Filtering**: Browse by *All*, *Electronics*, *Fashion*, *Footwear*, *Accessories*, and *Home & Living*.
- 🔄 **Multi-criteria Sorting**: Sort by Featured, Price (Low to High / High to Low), Highest Rated, or Most Popular.
- 🛒 **Interactive Slide-over Cart**:
  - Quantity controls (+/-) with automatic recalculation
  - Dynamic subtotal, free shipping threshold calculation, and total price preview
  - Promo code discounts system (e.g. `AURA15` for 15% off, `FREESHIP`)
- 💖 **Wishlist Drawer**: Save favorite products with instant badge updates and "Move to Cart" support.
- 👁️ **Product Quick View Modal**: Inspect high-resolution imagery, detailed specifications, ratings, and customer reviews.
- 💳 **Simulated Checkout Flow**: Full checkout form with shipping info, payment selection (Credit Card, PayPal, Cash on Delivery), and realistic order confirmation with unique generated Order IDs.
- 💾 **Local Storage Persistence**: Cart and Wishlist items remain preserved across page reloads.
- 🍞 **Interactive Toast Notifications**: Instant feedback for user actions.

## 🚀 Getting Started

### 1. Run Locally
No server or build process required! Simply double-click `index.html` in your file explorer to open it in your default web browser:

```powershell
# Or open directly via terminal:
start index.html
```

Or serve with Python or any local web server if preferred:
```powershell
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## 📤 How to Push This Project to GitHub

Follow these simple steps to push this project to your GitHub account:

### Step 1: Create a New Repository on GitHub
1. Go to [GitHub.com](https://github.com/new) and log in.
2. Click the **+** icon in the top right corner and select **New repository**.
3. Name your repository (e.g. `aurastore` or `shopping-website`).
4. Leave it as **Public** and **DO NOT** check "Initialize this repository with a README".
5. Click **Create repository**.

### Step 2: Push from your local terminal
Open your terminal in this project directory and run:

```bash
# Clone the repository:
git clone https://github.com/surya192007/shopping-website.git
cd shopping-website
```

## 🌐 Deploy Free on GitHub Pages

You can host this website online for free using GitHub Pages:

1. Open your repository at **[github.com/surya192007/shopping-website](https://github.com/surya192007/shopping-website)**.
2. Go to **Settings** > **Pages** (under the "Code and automation" section on the left sidebar).
3. Under **Build and deployment** > **Branch**:
   - Select `main` from the dropdown.
   - Select `/ (root)` folder.
   - Click **Save**.
4. In 1–2 minutes, your live store will be published at:
   `https://surya192007.github.io/shopping-website/`
   `https://YOUR-USERNAME.github.io/shopping-website/`
